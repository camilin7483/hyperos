# Security

Security configuration and policies for HyperOS.

## Contents

| Path | Purpose |
|------|---------|
| `profiles/` | Security profiles (minimum, standard, hardened) |
| `policies/` | Security policy definitions |

## Planned Features

- Firewall management (nftables/iptables)
- AppArmor profiles
- Audit rules
- Secure boot support
- Filesystem encryption
- USB device control

## Status

Security profiles are in the planning stage. Basic profiles will be added during the v0.2 milestone.
