# Installer

HyperOS graphical installer (future).

## Purpose

Provide a user-friendly graphical installation experience for HyperOS, replacing the manual Arch Linux installation process.

## Planned Features

- Partition management
- Desktop environment selection
- User creation
- Bootloader configuration
- Encryption support
- Automatic partitioning

## Status

The installer is planned for v0.9. No implementation has begun.

## Approach

The installer will likely be based on Calamares, with HyperOS-specific modules for:

- Package selection
- Desktop configuration
- System tuning
