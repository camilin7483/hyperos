# Hyper Drivers

Driver manager for HyperOS.

## Responsibility

Hyper Drivers helps users install and manage hardware drivers through a graphical interface.

## Features (Planned)

- GPU driver detection and installation (NVIDIA, AMD, Intel)
- Printer driver management
- Wireless firmware management
- Driver status overview
- Automatic hardware detection

## Dependencies

- `core/libraries/libhyper-system` for hardware detection
- `core/libraries/libhyper-package` for driver package installation

## Target Version

v0.8
