# Hyper Store

Application store for HyperOS.

## Responsibility

Hyper Store provides a graphical interface for discovering, installing, and managing software on HyperOS. It wraps pacman and AUR helpers with a user-friendly interface.

## Features (Planned)

- Package browsing by category
- Search with filtering
- One-click install/remove
- Update management
- Screenshots and descriptions
- User ratings (future)

## Dependencies

- `core/libraries/libhyper-package` for package operations
- `core/libraries/libhyper-config` for repository config

## Target Version

v0.5
