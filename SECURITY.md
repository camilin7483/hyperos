# Security Policy

## Supported Versions

HyperOS is currently in pre-release development. No stable releases are available yet.

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please follow these steps:

1. **Do not** disclose the vulnerability publicly
2. **Do not** create a public GitHub issue
3. Send details to the maintainers through a private channel

## Security Practices

- All code is reviewed before merging
- Dependencies are regularly audited
- Security profiles are maintained in `security/`
- Firewall rules are configured by default
- System services follow the principle of least privilege

## Secure Development

- Avoid introducing hardcoded credentials
- Never commit secrets or keys
- Use secure defaults for all configurations
- Follow the Arch Linux security guidelines
