# Documentation

Technical documentation for HyperOS.

## Contents

- `decisions/` — Architecture Decision Records (ADRs)
- `development/` — Developer guides and references

## Purpose

This directory contains all technical documentation beyond the root-level documents. Each document should explain a specific aspect of the system architecture, development workflow, or design decision.

## Adding Documentation

- Use Markdown format
- Keep documents focused on a single topic
- Update table of contents when adding documents
