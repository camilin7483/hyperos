# DBus

DBus service definitions and interfaces for HyperOS.

## Purpose

DBus is the primary system-level communication bus. All HyperOS services expose their functionality through DBus interfaces.

## Planned Services

- `org.hyperos.System` — System information and control
- `org.hyperos.Updates` — Update management
- `org.hyperos.Drivers` — Driver management
- `org.hyperos.Profiles` — Performance profiles

## Status

DBus interfaces are being designed.
