# Hyper Gaming

Gaming mode tools for HyperOS (future).

## Purpose

Hyper Gaming provides tools and configurations optimized for gaming, including GPU switching, performance tuning, and compatibility layers.

## Responsibility

- Gaming performance profile
- GPU switching (hybrid graphics)
- Wine/Proton management
- Game launcher integration
- Performance overlay (MangoHud)
