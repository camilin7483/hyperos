# Hyper CLI

Command-line tools for HyperOS.

## Purpose

Hyper CLI provides command-line access to HyperOS system management functions. It enables terminal-based administration for advanced users.

## Responsibility

- System information commands
- Configuration management
- Performance profile switching
- Service management
- Update management

## Commands

```bash
hyperos system info
hyperos config get <key>
hyperos config set <key> <value>
hyperos profile list
hyperos profile set <name>
hyperos update check
hyperos service list
```
