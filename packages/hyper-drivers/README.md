# Hyper Drivers

Driver management for HyperOS.

## Purpose

Hyper Drivers provides a graphical interface for installing and managing hardware drivers, including GPU drivers, printer drivers, and firmware.

## Responsibility

- GPU driver installation (NVIDIA, AMD, Intel)
- Printer driver management
- Wireless firmware management
- Driver updates
- Hardware detection
