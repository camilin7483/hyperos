# Hyper Installer

System installation configuration for HyperOS.

## Purpose

Hyper Installer configures the HyperOS system during installation. It handles initial setup tasks such as user creation, locale configuration, and desktop environment selection.

## Responsibility

- Initial system configuration
- Post-installation setup
- Desktop environment selection
- Systemd service enablement
- First-boot configuration
