# Branding

Visual identity assets for HyperOS.

## Design Philosophy

- Minimal
- Clean
- Professional
- Technical

## Color Palette

| Color | Hex |
|-------|-----|
| Black | #000000 |
| Dark Gray | #1A1A1A |
| Medium Gray | #2D2D2D |
| White | #FFFFFF |
| Electric Blue | #00AEEF |

## Contents

- `logo/` — HyperOS logo in multiple formats
- `plymouth/` — Plymouth boot splash theme
- `grub/` — GRUB bootloader theme
- `wallpapers/` — Desktop wallpapers
- `sddm/` — SDDM login screen theme
- `icons/` — Application icons

## Usage

All branding assets are placeholders during early development. Final artwork will be created as the project approaches v1.0.
