# GRUB Theme

HyperOS GRUB bootloader theme.

## Status

Placeholder. Final theme will be created during the v0.2 milestone.

## Directory Structure

```
grub/
├── background.png     # Boot background
└── grub-theme/
    └── theme.txt      # GRUB theme configuration
```

## Installation

The theme is installed to `/boot/grub/themes/hyperos/` and configured in `/etc/default/grub`.
